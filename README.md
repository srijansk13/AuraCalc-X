# ✨ AuraCalc X — Futuristic Premium Calculator

A fully responsive, ultra-modern futuristic calculator web application built using **HTML, CSS, and Vanilla JavaScript**.

AuraCalc X combines premium UI/UX, smooth animations, lightning-fast responsiveness, and advanced calculator functionality into a cinematic frontend experience inspired by modern SaaS applications.

# ✨ Features

## 🧮 Calculator Features
- Addition, subtraction, multiplication, division
- Percentage calculations
- Decimal support
- Parentheses support
- Real-time calculations
- Keyboard support
- Clear & delete functionality
- Expression handling

---

## ⚡ Scientific Functions
- Square root
- Powers & exponents
- Logarithmic calculations
- Trigonometric functions
  - sin
  - cos
  - tan
- π and e constants

---

## 💾 Memory Functions
- MC (Memory Clear)
- MR (Memory Recall)
- M+ (Memory Add)
- M- (Memory Subtract)
- MS (Memory Store)

---

## 📜 History System
- LocalStorage-based calculation history
- Reusable previous calculations
- Smooth animated history drawer
- Lightweight responsive design

---

## 🎨 Premium UI/UX
- Futuristic SaaS-inspired interface
- Glassmorphism design
- Neon glow effects
- Smooth animations
- Dark / Light themes
- Mobile-first responsive layout
- Ultra-fast interactions
