✨ AuraCalc X — Futuristic Premium Calculator

A fully responsive, ultra-modern futuristic calculator web application built using HTML, CSS, and Vanilla JavaScript.

Designed with a premium SaaS-inspired UI/UX, AuraCalc X combines smooth interactions, lightning-fast responsiveness, elegant glassmorphism aesthetics, and advanced calculator functionality into a cinematic frontend experience.
